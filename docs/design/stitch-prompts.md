# Google Stitch

## Objetivo

Google Stitch foi utilizado para exploração de UX e direção visual.

Não foi utilizado para definir regras de negócio ou arquitetura.

## Prompt inicial

Design a responsive web application called EliteTickets.

PRODUCT

EliteTickets is an event ticket platform.

There are three experiences:

1. Customer
2. Event Organizer
3. Gate Staff

CUSTOMER

Users browse published movie events.

Each event displays:
- poster
- title
- date
- time
- venue
- ticket price

Users can:
- search events
- view event details
- select ticket quantity
- review order
- perform simulated payment
- receive approved or declined feedback
- access My Tickets
- open a digital ticket
- display its QR code
- share the ticket through a link

ORGANIZER

Users can:
- search an external movie catalog
- select a movie
- define date
- time
- venue
- capacity
- price
- publish the event
- view sold and available inventory

GATE

Gate staff:
- select an event
- scan a QR code
- manually enter a ticket code

Validation states must be unmistakable:

VALID
INVALID
ALREADY USED
WRONG EVENT

VISUAL DIRECTION

Avoid generic AI SaaS aesthetics.

Do not use:
- excessive gradients
- glassmorphism
- generic hero sections
- excessive dashboard statistic cards

Use visual references from:
- physical tickets
- cinema admission tickets
- event posters
- editorial typography

The digital ticket should visually resemble a real premium ticket.

Customer experience must be mobile-first.

Gate interface should prioritize readability and speed.

Organizer experience may be desktop-oriented.

Use a single distinctive accent color and strong typography hierarchy.

Accessibility and high contrast are required.

## Variantes

Foram avaliadas diferentes alternativas antes da escolha final.

## Critérios de decisão

- identidade relacionada ao domínio de ingressos;
- facilidade de navegação;
- experiência mobile;
- destaque adequado ao QR;
- contraste;
- velocidade da interface de portaria;
- ausência de aparência genérica de dashboard SaaS.

## Papel humano

A ferramenta produziu alternativas.

A escolha das variantes, descarte das alternativas e refinamento
visual foram realizados manualmente.
